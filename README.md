# cufetch
Hi! I'm learning C++ and decided to write my own fetch, so don't take this project seriously.

# How to install?

*Clone the repository*

```
git clone https://github.com/horeefee-gif/cufetch.git
cd cufetch/
```

*Run cufetch or compile*

```
chmod +x cufetch
./cufetch
```

*or*

```
cd src/
g++ -O2 -std=c++17 cufetch.cpp -o cufetch
chmod +x cufetch
./cufetch
```

# How to run with one command?

```
sudo cp cufetch/cufetch /usr/local/bin/cufetch

```
